Parts of other projects inside the app

Breadboard Bench runs its Python engine in the browser with the software below, copied unchanged so the app works offline. Each keeps its own licence.

  • Pyodide 314.0.7 (folder pyodide/): Mozilla Public License 2.0. Licence and notice. Source code: github.com/pyodide/pyodide/tree/314.0.7.
  • CPython 3.14.2, the Python interpreter and standard library inside Pyodide: PSF License Agreement, with the licences of the software built into it (libffi, expat, zlib, mpdecimal, HACL* and others). Licence and notices.
  • Emscripten 5.0.3 runtime, part of Pyodide's files: MIT licence (or University of Illinois/NCSA). Licence.
